### Explanation of Each Folder and File

#### `data/`
This folder contains all the data used in the project.
*   **`raw/`**: The original, untouched datasets as downloaded. Keeping this separate ensures you can always go back to the source.
*   **`processed/`**: Cleaned and pre-processed data ready for the models (e.g., text cleaning, train/val/test splits saved in a convenient format like JSON or CSV).

#### `notebooks/`
Jupyter notebooks are for exploration, debugging, and visualization.
*   `01_data_exploration.ipynb`: Analyze dataset statistics, text lengths, label distributions.
*   `02_cognition_system_testing.ipynb`: A scratchpad to test LLM prompts and see what kinds of truth values are generated for individual news articles.
*   `03_results_visualization.ipynb`: Create plots and charts from the final results tables.

#### `prompts/`
Storing prompts separately from code makes them easy to find, read, and modify.
*   `question_templates.json`: Contains the core question templates (`P1` to `P8`) in a structured format.
*   `intervention_templates.json`: The additional questions used for the controllability experiments.

#### `results/`
This folder is for all the artifacts generated by your experiments. It should be added to `.gitignore`.
*   **`models/`**: Saved weights of the trained **Decision System** (the DNF Layer).
*   **`logs/`**: Detailed logs from each experiment run, including hyperparameters, epoch-by-epoch performance, and final scores.
*   **`tables/`**: Machine-readable versions (e.g., CSV) of the result tables from the paper for easy analysis.
*   **`extracted_rules/`**: The human-readable logical rules generated by `scripts/extract_rules.py`.

#### `scripts/`
These are executable scripts that perform specific tasks.
*   `preprocess.py`: Runs the preprocessing steps on `data/raw/` and saves the output to `data/processed/`.
*   `run_cognition.py`: A crucial script that takes a processed dataset, runs it through the **Cognition System** to generate truth values, and caches these results. This is vital because querying LLMs is slow and expensive; this script allows you to run it once and then experiment with the Decision System many times quickly.
*   `train.py`: The main training loop. It loads the cached truth values and trains the DNF Layer model.
*   `evaluate.py`: Loads a trained model and evaluates it on a test set.
*   `extract_rules.py`: Implements the pruning algorithm (Algorithm 2) to simplify the DNF model and output its logic.

#### `src/` (or `teller/`)
The core source code of the TELLER framework, organized as a Python package.
*   `cognition_system.py`: A class or set of functions to handle interfacing with LLMs (e.g., via Hugging Face `transformers` or an API), formatting prompts, parsing "Yes/No" answers, and calculating the truth values (`μ`) as described in **Equations (1) and (2)**.
*   `decision_system.py`: A PyTorch `nn.Module` that defines the custom DNF Layer, including the conjunctive (`SL_A`) and disjunctive (`SL_V`) layers.
*   `pipeline.py`: A high-level class `TELLER` that connects the two systems. A method like `predict(news_text)` would first call the cognition system and then feed its output to the decision system.
*   `data_loader.py`: Defines the PyTorch `Dataset` and `DataLoader` for efficiently loading the processed data (specifically, the cached truth values) for training the decision system.
*   `baselines.py`: Contains functions to run the baseline models (Direct, Few-shot COT, etc.) for comparison.
*   `utils.py`: A place for utility functions used across the project, such as setting up a logger, calculating Macro-F1 score, or saving model checkpoints.

#### `configs/`
Using configuration files (like YAML or JSON) is much better than hardcoding parameters. It makes experiments easy to define and reproduce. Each file would specify things like:
*   LLM to use (e.g., `meta-llama/Llama-2-13b-chat-hf`).
*   Path to dataset and model checkpoints.
*   Hyperparameters for the DNF Layer (learning rate, batch size, number of conjunctions `C`).
*   Mode (e.g., `train`, `evaluate`, `cross-domain`).

#### Root Files
*   `.gitignore`: Essential for ignoring folders like `results/`, `data/`, Python cache (`__pycache__`), etc.
*   `README.md`: The most important file. Explains what the project is, how to set it up (`pip install -r requirements.txt`), and how to run the key scripts.
*   `requirements.txt`: A list of all Python dependencies (e.g., `torch`, `transformers`, `scikit-learn`, `pandas`).
*   `LICENSE`: The license for your code (e.g., MIT, Apache 2.0).
